# 소닉 애니메이션 뷰어 개발 명세서 (PRD)

## 1. 개발 및 커밋 기본 원칙
1. **커밋 언어**: 모든 커밋 메시지는 **반드시 명확한 한글**로 작성한다.
2. **점진적 개발 및 로컬 커밋**: 한꺼번에 구현하지 않고 작은 기능 단위로 점진적으로 개발하며 로컬에 커밋을 남긴다. **원격 저장소 푸시(Push)는 하지 않는다.**
3. **커밋량 및 형식**: **LEC 08 브랜치의 커밋 형식과 분량을 적극 참고**하여, 의미 있는 단위 커밋을 기록한다.

---

## 2. 프로젝트 개요
* **프로젝트명**: 소닉 애니메이션 뷰어 (`sonic_animation_viewer.py`)
* **목표**: `pico2d` 라이브러리를 활용하여 단일 소스 파일로 소닉 스프라이트 시트의 **12종 동작(총 76프레임)**을 화면 중앙에서 순차적으로 재생하고 검증하는 순수 2D 애니메이션 뷰어 제작
* **개발 환경**: Python 3.x, pico2d
* **대상 리소스**: `Labs/LEC09/sonic-sprite.png` (원본 해상도: 399 × 525 px, 상/하단 텍스트 제외 10개 행 순수 스프라이트)

---

## 3. 화면 및 그래픽 시스템 사양

### 3.1 캔버스 및 출력 위치
* **캔버스 해상도**: **1200 × 800** 픽셀
* **출력 위치**: 캐릭터 좌표 이동 없이, **화면 정중앙 `(x = 600, y = 400)`**에 고정되어 제자리에서 애니메이션을 재생한다.
* **배경 및 UI**:
  * 투명/배경색 클리어 후 화면 중앙에 스프라이트 출력
  * 화면 좌상단에 현재 재생 중인 **애니메이션 이름**과 **반복 횟수 (1/5 ~ 5/5)** 표시

### 3.2 스프라이트 렌더링 규격
* **확대 배율**: 원본 대비 **4배 확대** 출력 (`SCALE = 4`)
* **렌더링 방식**: `clip_draw`를 사용하여 중심점 기준 4배 크기로 확대 출력
* **좌표 변환 규칙**:
  * 스프라이트 시트 높이: `IMAGE_H = 525`
  * 시트 상단 기준 y좌표(`top`)를 pico2d 좌하단 기준 `bottom`으로 변환:
    $$\text{bottom} = 525 - (\text{top} + \text{height})$$

---

## 4. 핵심 기능 및 재생 제어 규칙

### 4.1 재생 제어 흐름
1. **제자리 재생**: 좌표 이동 없이 화면 중앙 `(600, 400)`에서 순수 애니메이션 프레임만 재생한다.
2. **5회 반복 재생 (`REPEAT_COUNT = 5`)**: 각 동작 애니메이션은 1사이클을 기준으로 **정확히 5회 반복** 재생한다.
3. **1초 정지 (`PAUSE_TIME = 1.0`)**: 5회 반복 재생 완료 직후, **마지막 프레임 화면을 유지한 채 정확히 1초간 정지**한다. (정지 중에도 창 닫기 및 ESC 키 입력 처리 유지)
4. **다음 동작 전환**: 1초 정지가 끝나면 다음 동작으로 자동 전환하여 재생을 시작한다.
5. **무한 순환**: 마지막(12번째) 동작의 5회 재생 및 1초 정지가 끝나면 다시 첫 번째 동작부터 **무한 반복**한다.
6. **안전 종료**: `ESC` 키 입력 또는 창 닫기(`SDL_QUIT`) 이벤트 발생 시 즉시 루프를 안전하게 종료하고 리소스를 해제한다.

## 6. 최종 완료 기준 (Definition of Done)
1. **단일 파일 실행**: `python Labs/LEC09/sonic_animation_viewer.py` 실행 시 1200×800 창에서 오류 없이 즉시 구동.
2. **화면 중앙 제자리 재생**: 캐릭터의 이동 없이 화면 중앙 `(600, 400)`에서 4배 크기로 출력.
3. **12종 76프레임 완전성**: 12종 동작, 총 76프레임이 겹치거나 잘림 없이 완벽하게 독립된 동작으로 분할되어 자연스럽게 재생.
4. **전환 규칙 준수**: 각 동작 5회 반복 $\rightarrow$ 마지막 프레임 유지한 채 1초 정지 $\rightarrow$ 다음 동작 전환 $\rightarrow$ 12종 완료 후 무한 순환.
5. **커밋 요건**:
   * 커밋 메시지는 **한글**로 작성.
   * **원격 푸시 없이 로컬 커밋으로만 유지**.
