게임이란 : “가상 월드에 존재하는 여러 객체들의 상호작용”을 시뮬레이션하고 그 결과를 보여주는(렌더링) 것

2D 게임 : 현재 진행 중인 게임 가상 월드의 내용을 화면에 2D 그림으로 보여주는 것

## 객체지향

객체 지향 <-> 절차 지향
객체 중심, 객체 위주 프로그래밍

절차지향은 절차를 쭉 나열, 객체 지향은 객체를 쭉 나열한 것이다.

1. 객체 지향을 하기 위해서는 객체를 찾아내야 한다.
-> 모든 것들을 객체로 표현할 필요 없고 꼭 게임에 필요한 만큼만 객체로 사용한다.(추상화(Abstraction)) - 소년, 땅
- 꼭 필요로 하는 객체들만,
- 꼭 보여줘야 할 내용만,
- 꼭 보여줘야 할 움직임만


2. 객체의 속성 정하기
속성 – 게임 객체의 현재 상태
객체의 속성은 매우 많기 때문에 이 게임을 위해서 필요한 속성만 사용해야 한다.(추상화(Abstraciton))

소년 : X - 위치를 표현하기 위해, 이미지 - 소년의 모습을 보여주기 위해

3. 객체의 행위 정하기
행동 – 시간에 따라, 혹은 이벤트에 반응해서 상태가 변하는 방식
객체의 상태를 바꾸어 주는 것
객체는 왜 움직이는가?
-> 객체의 상호작용(땅과 소년의 상호작용) - 행위

**속성 + 행위 = 소년 객체**

## 클래스 
- 유사한 여러 객체들에게 공통적으로 필요로 하는 데이터와 이 데이터 위에서 수행되는 함수들을 정의하는 소프트웨어 단위.
- 객체를 찍어내는 “도장”

객체를 생성하려면?
- 클래스라는 틀을 이용하여 붕어빵 찍어내듯이 객체를 생성하게 된다.
- 찍어내는 과정을 Object Instantiation이라고 한다.


오브젝트 = 인스턴스 같은 말
인스턴스(Instance) : 어떤 클래스로부터 생성된 객체를 뜻한다.
